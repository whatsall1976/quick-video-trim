# Quickstart (local)

Prereqs: Node.js + npm.

```bash
npm install
```
Install dependencies.

```bash
npm run dev
```
Start the dev server (Vite). Open the printed localhost URL.

```bash
npm run build
```
Build production assets into `dist/`.

```bash
npm run preview
```
Serve the production build locally (Vite preview).

Notes:
- First export/detection may download FFmpeg.wasm / model assets (needs network).
